# Notes for Claude Code

## What this is
A single-page game app (`public/index.html`) plus one Vercel serverless function (`api/judge.js`) that calls OpenRouter to judge open-ended answers in four games: Word Spread, Beat the 7, Recall Rebuild, Missing Link.

Users are 1st-year B.Tech students in India. All game content must stay within their Sem 1 syllabus: Python basics up to dictionaries, HTML/CSS (Flexbox, Grid, Tailwind), Git and command line, number systems and bitwise, quantitative aptitude, GenAI basics. No DSA.

## First task: choose the cheapest reliable model
1. Check `.env.local` has `OPENROUTER_API_KEY`.
2. Run `npm run models` to list the cheapest text models.
3. Pick 4–6 candidates. Prefer models that support `response_format` (the `json` column), and skip free models unless the user asks (they are rate-limited and can disappear).
4. Run `npm run test:judge -- <id1> <id2> ...`.
5. Choose the cheapest model with: accuracy >= 90%, zero unusable outputs, median latency under about 2000 ms. If none qualifies, try the next price tier.
6. Set `OPENROUTER_MODEL` in `.env.local`, and tell the user to set the same value in Vercel.
7. Report a short table: model, accuracy, median ms, cost per 1,000 checks.

## Rules
- Never expose the API key to the browser. All model calls go through `api/judge.js`.
- Keep the fallback: if the judge fails, the games must still work with built-in matching.
- Student text is untrusted. Keep it inside the tags in `prompts.js`, keep input length limits in `validatePayload`, and only use outputs that pass `validateResult`.
- Keep `temperature: 0` so the same answer always gets the same verdict.
- Before changing any game content, check it: one correct answer per puzzle, Indian context, Sem 1 topics only. Run Python snippets to confirm outputs.
- When a judging mistake is found, add it to `scripts/gold.mjs` first, then adjust the prompt, then re-run `npm run test:judge`.
- Keep plain, simple English in anything students read.

## English Adda (branch english-adda)

- Code: `public/english/english.js` + `english.css`, server `api/english.js`, tables `english_*` in `scripts/db-setup.mjs`.

He speaks in a male Kokoro voice, `am_puck` (`MITHU_VOICE` in `scripts/english-lines.mjs`; owner asked for male, "pick any for now"); listening sentences keep af_heart.
- Who sees it: batches in env `ENGLISH_BATCHES` (comma list, default `DEMO`, `ALL` = everyone). Pilot is DEMO only until the product owner says go. The tab stays hidden for everyone else.
- Daily: goal 15 active minutes (own timer, counted only while a game or the level check runs), fresh content closes at 25 minutes (DEMO: no limit). Streak = goal days, one missed day forgiven per 7 days.
- Adda points never mix with Brain Gym or Drive points. Skill levels (voc, gra, lis, rea, wri; 1–8) are private: never shown to other students or on the leaderboard.
- No speaking features. English only (no Hindi/Telugu/Tamil hints). Never call anything a "test" in student copy.
- Content: Claude writes it in bulk, scripts check it, then a separate reviewer agent checks it as a third person before it ships. Follow the Indian English policy in Research §6 (accept / formal-only / correct). Use short English names for student-facing things.
- Level check ("Find your level"): content + scoring live server-side in `api/_lib/english-check.js` (answers never sent to the browser). Actions checkstart/checknext/checkdone in `api/english.js`. Test accounts redo it from the home link.
- Audio: after ANY change to Mithu's lines (MITHU_LINES block in `english.js`) or listening content (level check Catch It, Echo sentences), run `python scripts/english-voice.py`. Listening sentences are "secret": recorded under sha1(voice|speed|text) names and kept OUT of the public manifest, so students can't read answers.
- Game redesign (Nov 2026): research and lineup in `English Adda/English Adda — Game Research 2.md`. Games must feel like games, not worksheets: one action, no Next button, a live score, a personal best. Jumble became **Express** and Spot & Fix became **Hop** (first called Flick; the id is still `flick`; same content files, jumble.js and spotfix.js). Word Groups is out of play (owner: hard and boring); its code and content are kept but it is not in `BUILT`. **Dive** took its place (first built as a tile-matching game called Pair Up, which the owner rejected twice; the id is still `pairup` and the pairs are in `api/_lib/english/pairs.js`). The three wrong fish come from pairs of the same kind near the level that cannot be mixed up with the target: pairs of one kind that a student could mix up share a `set` (a name or a list); the content check enforces shared-word and preposition clashes and checks every set of four fish. Catch It (gap version) was built as **Echo**, Trim as **Munch** and Fast Read as **Pigeon Post** (Nov 2026). Still to build: Vault Run, Tone Dial.
- Every game IS its scene, the way Lumosity builds each game around one world (owner rejected scenes that are only decoration, and tile-matching with birds as "amateurish"). The thing the student reads must be an object in the scene, the answer an action in it, and a creature needs the student's help: **Express** = phrases are coaches, tap them onto the train; **Hop** (game id `flick`) = a squirrel wants to cross a river; phrases are stepping stones; Hop if the sentence is right, or Wait and then TAP THE WRONG STONE (it sinks, the right one rises, he crosses; hop onto a wrong sentence and he falls in at the wrong stone); **Dive** (game id `pairup`, content `pairs.js`) = a hungry kingfisher; the sign shows a word and what to find (opposite of / same as / goes with / a picture), four lily pads carry words and a small fish hides under each; tap the right pad and he dives for the fish (words are on pads, not on fish, so the bird is the biggest animal: owner noticed fish larger than the bird); **Real or Fake** = a koel hides fake eggs in a crow's nest; each word is an egg; a real word is a real egg (keep it, a chick hatches), a wrong spelling or made-up word is a fake egg (push it out; keep it and a koel chick hatches); the meaning or right spelling stays 5 s after a right answer and 7 s after a miss (owner needs reading time), and missed real words are offered to the Word Vault on the end card. **Munch** (writing, content `munch.js`) = a hungry goat under a hedge; each word is a leaf and exactly one word is extra (`more better`, `explain about`, `went to abroad`, `Although… but`); tap it and he eats it; tap a needed word and he spits it out ("Bleh! I need that one."), then eats the real extra word so the fixed sentence always shows; **Pigeon Post** (reading, id `post`, content `notes.js`) = a pigeon brings a short note (chat, notice, email, poster); the tag asks one question; tap the house whose sign has the answer (window lights up) — wrong answers use words from the note; **Echo** (listening, content `echo.js`) = a bat in a dark cave; the sentence plays ONCE (Miss Replay may replay), it is on the cave wall with 1-3 gaps; tap one of 3 words per gap, a right word lights a lamp; options must sound clearly different (the content check bans homophones), clips are secret like Catch It. Munch, Pigeon Post and Echo were added Nov 2026 so every skill has a game. A new game needs a scene of this kind before it is built. No arcade action on top of the language task. Squirrel hops are 135 ms (owner found 95 ms too fast). Class names `pop` and `pick` are taken by page-level styles in index.html: prefix new state classes or check first.
- Students' real English (from 21,000 in-app feedback comments, Nov 2026): most write one word ("good", "nothing", "ntg"); typical sentences are "Sir does not explained all the concepts", "the new things telled in the workshop", "class is not their"; some ask for Telugu. Write every instruction in short sentences with the commonest words (no "phrase", "partner", "perch"); expect most play at levels 1-3; tense, articles, prepositions and spelling are the errors worth teaching.
- Run games (`RUN` in `english-games.js`, `RUN_GAMES` in `english.js`): Chill (no clock) and Rush (a clock per item; opens after one round with 80%+ right, always open for DEMO). Score = 100 per right answer x streak multiplier, plus speed in Rush; `runScore` on the server is the number that is saved (`english_rounds.meta`), `runHit` in the page mirrors it. Hop card ids are `<spotfix id>:g` (right) or `:b` (wrong); the answer is `true` (Hop) or `{ p: stone }` (Wait + the stone tapped), and a wrong sentence counts as right only if the tapped stone is the one with the mistake. Express: about half the coaches are already on the train (`expressFixed`, always the first one; fixed per sentence), the student taps the rest left to right; the page sends every tap and the server replays them. Misses are replayed from the end card (Miss Replay, not scored).
- Games (step 3): content with answers lives server-side in `api/_lib/english/` (words.js, fakes.js, jumble.js, spotfix.js, groups.js), engine in `api/_lib/english-games.js`. The server picks each round (70% at level, 20% below, 10% above, unseen first) and sends it with answers for instant feedback; on save it re-scores only the FIRST attempt per item. Level up = 80%+ over the last 20 answers at the current level on 2+ days (DEMO: 1 day). Levels never drop.
- To make a game playable: add it to `BUILT` in `api/_lib/english-games.js` AND set `built: true` in `GAMES` in `english.js` (both must match).
- After any content change: `node scripts/english-content-check.mjs` (must pass), then a reviewer-agent pass. Word Groups: each word must fit exactly one group; only very common words (owner: students know simple words); tiers 1–2 show the group names as clues, tier 3 has a hint button. Real or Fake fakes are misspellings (`spell`) and wrong word forms (`form`), never nonsense strings, and never an accepted British/American variant. Words: use `avoid: [...]` for near-synonyms so the vault never offers both.
- Test accounts can jump into any game from the console: `Adda.open('express', 6)`, `Adda.open('flick', 2)`, `Adda.open('pairup', 1)`, `Adda.open('munch', 1)`, `Adda.open('post', 3)`, `Adda.open('echo', 2)`.
- After `english.css`/`english.js` changes, raise their `?v=` numbers in `index.html`. The dev server caches `api/_lib` modules: restart it after editing them.
- Local testing without the Vercel CLI: `npm run dev:local` (scripts/dev-server.mjs serves `public/` and runs `api/*.js` with `.env.local`, the dev DB) on http://127.0.0.1:3000.
